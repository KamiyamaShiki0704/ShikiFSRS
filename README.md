# ShikiFSRS

Rust SDK for ELDEN RING and ELDEN RING NIGHTREIGN.

- ER WW 1.17.1: task, character, parameter, input, resource, sound, summon and HUD interfaces.
- NR EXE 1.3.3.0: task, parameter and builtin Goal catalogs; experimental roots, tasks, character modules, attributes, rigid transforms, action-request masks and original/resolved IDs and bounded ID-table lookup, goal-action control state, Think action-event queues and predicate transitions, self-target character/effect-ID lookup, character-to-ComThink association and selected Goal roots and bounded child/tree observations and float parameters, builtin definition bindings, GoalExecAction request publication, special-effect queries and ID tier plans, default native effect addition, removal and limit operations; PARAM rows, typed fields and schema checks.
- Shared checked memory access, PE/RTTI inspection, signatures and callback management.

Native runtime interfaces are experimental and have not been validated in-game.
