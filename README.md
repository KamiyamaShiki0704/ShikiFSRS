# ShikiFSRS

Rust SDK for ELDEN RING and ELDEN RING NIGHTREIGN.

- ER WW 1.17.1: task, character, parameter, input, resource, sound, summon and HUD interfaces.
- NR EXE 1.3.3.0: task, parameter and builtin Goal catalogs; experimental roots, tasks, characters, transforms, action ID queries and requests, Goal trees and parameters, builtin and script definition bindings, script dispatch and FollowPath input plans, GoalExecAction publication, special-effect queries and native operations; PARAM rows, typed fields and schema checks.
- Shared checked memory access, PE/RTTI inspection, signatures and callback management.

Native runtime interfaces are experimental and have not been validated in-game.
