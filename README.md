# ShikiFSRS

Rust SDK for ELDEN RING and ELDEN RING NIGHTREIGN.

- ER WW 1.17.1: task, character, parameter, input, resource, sound, summon and HUD interfaces.
- NR EXE 1.3.3.0: task and parameter catalogs; experimental task group, world player, character and parameter resource readers.
- Shared checked memory access, PE/RTTI inspection, signatures and callback management.

Native runtime interfaces are experimental and have not been validated in-game.
